# LOBA

**Localización de objetos anómalos en entornos estructurados mediante plataformas robóticas móviles**

Página web del proyecto LOBA (Universidad Rey Juan Carlos, 2024–2026): **https://beltransen.github.io/LOBA/**

LOBA investiga cómo los robots móviles pueden percibir y localizar objetos que no conocen de antemano, y cómo esa percepción puede integrarse en los sistemas de localización y mapeado (SLAM) que les permiten navegar de forma autónoma. El proyecto se desarrolla en el [Intelligent Robotics Lab](https://github.com/IntelligentRoboticsLabs) de la URJC.
